## 🤳🏻 Aplikasi Absensi Face Detection

Aplikasi Flutter yang dibuat sebagai tugas **Ujian Tengah Semester (UTS)** untuk mata kuliah Mobile Programming dengan teknologi deteksi wajah dalam sistem absensi digital.  
Aplikasi ini menekankan **kreativitas**, **desain UI/UX**, dan **struktur kode yang modular dan efisien**.

> -Aplikasi absensi digital yang memanfaatkan teknologi deteksi wajah menggunakan Google ML Kit.  
> -Cocok untuk absensi karyawan, mahasiswa, atau keperluan kehadiran lainnya.  
> -Memiliki tiga menu utama: absensi dengan selfie (face detection), pengajuan cuti/izin/sakit, dan riwayat absensi.  
> -Menggunakan Firebase sebagai penyimpanan data real-time.

---

### ✨ Fitur Aplikasi

- ✅ Absensi menggunakan foto selfie dengan deteksi wajah otomatis
- ✅ Deteksi otomatis lokasi/alamat saat pengguna melakukan absensi
- ✅ Menu pengajuan Cuti, Izin, dan Sakit dengan fitur:
    - 📅 Pemilihan rentang tanggal (dari tanggal berapa sampai tanggal berapa) menggunakan kalender
- ✅ Riwayat absensi lengkap dengan fitur:
    - 🔍 Pencarian berdasarkan nama
    - 📆 Filter berdasarkan tanggal/kalender
    - 🔠 Filter berdasarkan urutan abjad
    - 📂 Filter berdasarkan jenis absensi (Hadir, Izin, Sakit, dll)
- ✅ Mode gelap (Dark Mode) untuk kenyamanan pengguna
- ✅ Kalender terintegrasi untuk melihat kehadiran per tanggal
- ✅ Integrasi dengan Google ML Kit untuk Face Detection
- ✅ Penyimpanan data menggunakan Firebase (Realtime Database / Firestore)
- ✅ Navigasi antar halaman yang intuitif (Absen, Izin/Cuti, Riwayat)
- ✅ UI responsif dan ramah pengguna
